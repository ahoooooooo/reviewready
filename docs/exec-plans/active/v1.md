Status: v1 trust-core hardening is implemented locally and the candidate is
under promotion review. The integration tree prepares the unreleased 1.0.6
package; local deterministic gates are green, but no production publication or
authoritative trusted-root claim is made until the external GitHub and npm
controls are verified. Bootstrap PR #47 is merged; the main ruleset bypass was
restored to its original empty state, and a post-merge readiness run is still
required before release.

## Working contract

Every behavior change follows red/green/regression: add a focused failing test,
implement the smallest safe change, run the focused test, then run the complete
quality gate. Readiness remains deterministic and separate from audit findings,
HTTP responses, and observability events.
