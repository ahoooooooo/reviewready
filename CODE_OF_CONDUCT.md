# Code of Conduct

## Our standard

ReviewReady welcomes contributors of every background and experience level. We
expect participants to communicate respectfully, assume good faith, and focus on
observable technical outcomes.

Examples of constructive behavior include:

- giving specific, actionable feedback;
- explaining tradeoffs and uncertainty;
- respecting different experience levels and communication styles;
- taking responsibility for submitted work, including AI-assisted work;
- protecting private data and reporting security concerns through the documented
  private process.

Unacceptable behavior includes harassment, threats, discriminatory language,
personal attacks, deliberate disruption, publishing another person's private
information, or using project spaces for spam and manipulation.

## Scope

This code applies in repository issues, pull requests, discussions, reviews, and
other public or private project interactions. Technical disagreement is welcome;
degrading another participant is not.

## Enforcement

Maintainers may edit or remove comments, close or lock discussions, reject
contributions, or temporarily or permanently restrict participation when behavior
violates this code. Enforcement decisions should be proportionate, documented
when appropriate, and avoid exposing unnecessary personal information.

Report conduct concerns privately through the maintainer contact shown on the
GitHub profile. Do not use a public issue for sensitive reports. Reports will be
reviewed as promptly and impartially as practical.

## Attribution

This project-specific code follows the principles commonly used in open-source
community codes of conduct while keeping the enforcement process appropriate for
a small maintainer-led project.
