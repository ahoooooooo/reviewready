# Maintainers

The following people currently have project-wide maintenance responsibility:

| Maintainer  | GitHub role | Scope                                     |
| ----------- | ----------- | ----------------------------------------- |
| @ahoooooooo | Owner       | Product, security, releases, and settings |

Maintainer status means responsibility for review, compatibility, security
triage, release integrity, repository settings, and community conduct. It is not
an endorsement of every contribution or a claim that all project activity has
been independently reviewed.

Role expectations, nomination, inactivity, removal, and succession are defined
in [GOVERNANCE.md](GOVERNANCE.md). Release operations additionally follow
`docs/releasing.md`; security reports follow [SECURITY.md](SECURITY.md).

GitHub's live repository permissions are authoritative. This file is the public
maintainer roster and must be updated in the same change as an intentional role
transition whenever disclosure is safe.
